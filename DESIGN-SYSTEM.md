# ZORAEL & CO. — DESIGN SYSTEM

## Colors
```css
:root {
  --zorael-ivory: #F5F1E8;
  --zorael-cream: #EDE6D8;
  --zorael-white: #FFFDF8;
  --zorael-charcoal: #171613;
  --zorael-black: #0D0D0B;
  --zorael-gold: #B79A5A;
  --zorael-muted-gold: #9F8650;
  --zorael-border: #D8CFBF;
}
```

Primary background = ivory.
Secondary surface = cream.
Elevated light = white.
Primary text = charcoal.
Deep contrast = black.
Gold = small accent.
Border = subtle 1px border.

Never replace the palette with random colors.

## Typography
Serif for hero/editorial/collection headings:
- Instrument Serif
- Cormorant Garamond
- Playfair Display

Sans for UI/body/navigation:
- Inter
- Geist
- Manrope

Keep the type system consistent.

## Spacing
Use a 4px base scale:
4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 80 / 96 / 120.

Use generous whitespace in editorial sections.

## Buttons
Primary: charcoal, light text, refined capsule geometry.
Secondary: light/transparent surface with charcoal border/text.
Gold buttons only when genuinely useful.

## Inputs
Opaque warm surfaces, subtle border, accessible focus state. No glass.

## Cards
Product cards should be mostly image + whitespace + typography. Do not over-box them.

## Radius
Pills for buttons/filters/tags. Medium radius where useful for inputs/cards. Images can remain rectangular. Do not radius everything.

## Icons
Use Lucide. Thin, simple, consistent.

## Shadows
Very restrained. Luxury comes from spacing, type, imagery and borders.

## Hover
Use subtle image swap, slight scale, underline, opacity or tiny translation.

## Forbidden
Glassmorphism, frosted glass, neon, loud gradients, excessive gold, thick borders, heavy shadows, cartoon/cyberpunk/gamer styling.
