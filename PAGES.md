# ZORAEL & CO. — PAGE SPECIFICATION

## Home `/`
Sections in this order:
1. Hero
2. Featured Categories
3. New Collection
4. Editorial Banner
5. Jewelry Feature
6. Hand Bag Feature
7. Brand Story
8. Newsletter
9. Footer

Hero: campaign image/video, minimal editorial headline, supporting line, primary CTA, exploration action.

Featured categories:
Clothes / Jewelry / Hand Bags / Collections.

New Collection: large editorial image, collection title, short description, CTA.

Editorial Banner: dramatic but restrained campaign section.

Jewelry and Hand Bag sections: premium imagery, different compositions.

Brand Story: short editorial statement + About CTA.

Newsletter: “The Zorael Edit”.

## Shop `/shop`
Title + intro + filters + product grid.
Filters: All / Clothes / Jewelry / Hand Bags / Collections.

## Product `/shop/[slug]`
Breadcrumb, gallery, title, price, description, variants, size if needed, quantity, Add to Bag, details, shipping, related products.

## Search `/search`
Large search field, suggestions if useful, results, category/collection matches, empty state.

## Collection `/collections/[slug]`
Hero, collection statement, product grid, optional editorial breaks.

## About `/about`
Brand statement, philosophy, craftsmanship, materials, visual story, shop CTA.

## Journal `/journal`
Featured story + article cards + tags.
Article detail: `/journal/[slug]`.

## Bag `/bag`
Items, quantities, prices, remove, subtotal, checkout CTA.
Empty bag: minimal message + Continue Shopping.

## Checkout `/checkout`
Contact, shipping, payment, order summary. Keep clean.

## Account `/account`
Sign in, create account, order history, profile, addresses. If backend is absent, make a UI shell only; do not invent a fake backend.

## Responsive
Every page must be intentionally designed for mobile, tablet and desktop.
